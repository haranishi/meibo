# 架電モードの要件

## 1. 対象と記録
- 1.1 When 一覧から架電モードを開始する, the meibo shall 現在の条件の対象を表示し、除外・消去済み企業を記録対象にしない。
- 1.2 When 結果と次回対応を保存する, the meibo shall 保存成功後だけ次の企業へ進み、最後は完了を表示する。
- 1.3 If 保存に失敗する, the meibo shall 入力と対象を保持し、再試行できるようにする。
- 1.4 When 利用者がスキップまたは終了する, the meibo shall 活動を作らず移動し、未保存入力があれば確認できるようにする。

## 2. 操作と表示
- 2.1 While 架電モードを利用する, the meibo shall 対象位置・社名・電話の有無・保存状態・次の操作を示す。
- 2.2 When キーボードで操作する, the meibo shall 保存して次へ進む操作を提供し、入力中の通常キーを奪わない。
- 2.3 The meibo shall 実際の電話発信や外部への送信を行わない。
- 2.4 When 対象の末尾または0件に到達する, the meibo shall 戻り先を表示して進行不能にならない。

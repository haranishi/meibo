# PRの画面試験を再現する

2026-11-11の本人依頼「skillを使ってテスト環境を整える」を、既存17.2・18.5・18.7の検証整備として扱う。製品の画面・保存規則・本番配備は変更しない。

## 受入条件

- PRのCIと手元で同じブラウザ試験を実行できる。試験失敗は終了値へ伝え、成功と扱わない。
- 固定依存とビルドしたCLIから、毎回新しい合成100社のDBを生成する。任意の既存DB・実データ・認証情報を受け取らず、`--allow-real`を使わない。
- 専用loopbackポートで待ち受け、既存プロセスを使い回さない。起動失敗・中断時も自分の子プロセスと一時DBを片付ける。
- 390/768/1440pxで一覧、検索、空結果からの復帰、詳細、活動保存、再読込、CSV出力を実操作する。JavaScript例外・console error・外部通信・本文の横はみ出しを検出する。
- 手元でブラウザから触れる専用テスト画面も起動できる。実データ用の4321番とは別にする。
- 通常のPRで秘密・課金・外部アカウントを必要としない。実サービスとの接続成功や本番公開を合格範囲に含めない。

## 設計

- 既存のRust品質・MSRV・クラウド試験は保持する。既存Node環境の`cloudflare/`に、固定したPlaywrightと独立したbrowser試験コマンドを足す。
- ブラウザの設定・fixtureサーバー・画面試験は`cloudflare/browser/`へ置き、既存の`node --test`と分ける。xtaskのRust製点検器と製品コードは変えない。
- Playwrightはfreshなloopbackサーバーを管理する。fixture起動器は既存CLIのdemo/serveを呼び、作成した一時ディレクトリだけを削除する。
- ローカルの一時DB・ビルド出力・Node依存・ブラウザキャッシュはSSDへ置く。CIではrunnerの一時領域へ置く。
- CIにはbrowser jobを追加する。権限はcontents read、秘密なし、有限timeout。ログ・画像・traceは合成データだけを扱う。
- 合否は実ブラウザの結果で判定する。今回の変更はテスト設定なので製品用feature flagは不要。

## 検証

既存Nodeチェック、固定依存導入、実CLIビルド、ブラウザ試験、起動失敗時の非ゼロ終了と後片付け、CI実行を確認する。コマンドと前提条件は開発者向け手順に残す。

# CSVで企業を出し入れし、ローカルで操作できるようにする

## 目的
list-engine は完成したが、Rustコードを書かずに企業を登録・取り出す入口がない。2026-10-23 の本人の続行依頼に基づき、次の仕様としてCSVとCLIを作る。

## 方針と範囲
既存の core を使い、企業だけを扱う逐次CSV変換と小さなCLIを追加する。固定項目だけで成立するため custom-fields より先に進める。画面・API・担当者・活動のCSV化は後続の仕様に残す。

## 制約
合成データだけで開発・検証する。既存企業DBには接続しない。2026-10-23の追加指示で、非公開リポジトリのcommit・push・PR作成・マージまで進める。外部公開・名称審査は保留する。既存 list-engine の性能目標・保存形式は変えない。

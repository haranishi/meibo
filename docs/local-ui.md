# ブラウザで合成デモを操作する

ローカルの営業ワークスペースで、ホーム・取引先・次回対応・ToDo・予定・商談を切り替えて使えます。取引先編集、担当者管理、活動、商談ボード、CSV取込/書出、保存ビューを試せます。実データDBは起動対象外です。汎用APIやMCPはまだありません。

## 起動する

リポジトリのルートで、未作成の名前を指定してデモDBを作り、起動します。既存DBを使う場合はdemoを実行せずserveだけを実行します。

```sh
cargo run -p meibo-app -- demo demo.db --rows 100
cargo run -p meibo-app -- serve demo.db --port 4317
```

表示された `http://127.0.0.1:4317` をブラウザで開きます。このMacの127.0.0.1だけで待ち受けます。ほかの端末や外部から公開する設定はありません。ポートが使用中なら別の番号を指定してください。80番はブラウザがポート番号を省略するとアクセスできないため、4317などを使います。

## 操作する

「取引先」でビューや絞込を選び、企業を開くと全幅のレコード画面へ移ります。上部の主要項目・営業段階と、詳細/関連タブ・活動欄から情報を確認できます。一覧に戻ると表示条件とページを維持します。「ホーム」は実際の状態別件数と本日の対応、「次回対応」は予定のある企業を日時順で表示します。

架電メモ・営業状態・次回対応の「現状のまま／設定する／解除する」を選んで保存します。再読込しても記録はDBに残ります。⌘K/Ctrl+Kで検索へ移れます。社名検索は全取引先が対象で、実行時にビュー/絞込を解除して案内します。ビュー/絞込の適用時も、検索を解除して案内します。

「新規」からデモの取引先を登録できます。法人番号が重複するとエラーを表示し、入力を保持します。ここで追加する内容も合成デモとして保存します。

CSVは全営業対象企業を書き出し、個人事業と除外した企業を省きます。画面の件数とCSVの件数は一致するとは限りません。「CSVを取り込む」から32MiB以下のUTF-8またはShift_JIS CSVを選べます。重複をエラーにするかスキップするか選び、確定済み件数を確認します。途中停止でも確定済み行は残ります。詳細は [CSVの使い方](csv.md)。

「取引先を編集」で主要情報を更新します。「関連」から担当者を追加し、個人情報を明示表示して編集できます。消去すると紐づくToDo・予定・商談も消去されます。活動は架電/訪問/メール記録/メモから選び、取消は履歴へ追記します。

「ToDo」は期限と完了/再開、「予定」は開始/終了、「商談」は名称・金額（JPY）・完了予定日・段階を保存します。企業の次回対応や営業状態とは独立して複数登録できます。ボードの金額は表示中の商談だけの合計です。段階は選択欄からキーボードでも変更できます。

一覧は既定/次回対応/最終活動の順序を選べます。条件・順序・表示列を名前付きビューとして、このブラウザに保存・復元・削除できます。共有されず、連絡先や活動メモは含みません。

## 停止と今回の試用

ターミナルで起動したときはCtrl+Cで停止します。DBは削除されません。

2026-10-23に起動した試用画面は `http://127.0.0.1:4317`、保存先は `.local-demo/trial-20261023-145240.db` です。バックグラウンド起動のPIDを `.local-demo/web-server.pid`、ログを `.local-demo/web-server.log` に記録しています。停止する場合は、そのPIDがこのプロジェクトのmeibo serveであることを確認してから終了します。

## 確認したこと

実ブラウザで検索・0件からの復帰・ページ前後・保存・再読込・CSVダウンロードを確認しました。保存通信が失敗した場合も入力を保ち再試行できます。390/768/1440pxの一覧と詳細を確認しました。外部フォント・CDN・利用状況送信は使いません。
